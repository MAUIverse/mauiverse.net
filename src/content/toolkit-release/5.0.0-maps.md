## CommunityToolkit.Maui.Maps v5.0.0 - Our Final Maps Release

The good news is that you no longer need us! In .NET 10, MAUI added Windows support to .NET MAUI's own `Map` control, meaning `CommunityToolkit.Maui.Maps` is no longer needed. 

We recommend moving to .NET MAUI's official [`Microsoft.Maui.Controls.Maps`](https://www.nuget.org/packages/Microsoft.Maui.Controls.Maps) package.

**What changes in this release**
- `UseMauiCommunityToolkitMaps`, its `AppBuilderExtensions` class and the Windows handler `MapHandlerWindows` are marked `[Obsolete]`.
- The `CommunityToolkit.Maui.Maps` code will be removed from our repo when we merge our .NET 11 PR (#3331)

**How to migrate**
1. Remove the `CommunityToolkit.Maui.Maps` package, its `using CommunityToolkit.Maui.Maps;` directives and the `UseMauiCommunityToolkitMaps()` call.
2. Add the [`Microsoft.Maui.Controls.Maps`](https://www.nuget.org/packages/Microsoft.Maui.Controls.Maps) package. The toolkit package used to reference it for you.
3. Call `builder.UseMauiMaps()` in `MauiProgram.cs` on every platform.
4. On Windows, also add an Azure Maps key: `builder.ConfigureEssentials(essentials => essentials.UseMapServiceToken("YOUR_AZURE_MAPS_SUBSCRIPTION_KEY"))`. Without a valid key the Windows map shows no map data. See [Manage authentication in Azure Maps](https://learn.microsoft.com/azure/azure-maps/how-to-manage-authentication) to get one.

**What to expect on Windows**
.NET MAUI's Windows map is the WinUI 3 `MapControl` backed by Azure Maps.
- Supported: `MoveToRegion`, the `Street`, `Satellite` and `Hybrid` map types, traffic, scrolling, zooming and pins.
- Not supported yet: `IsShowingUser`, polygons, polylines and circles in `MapElements`, pin labels and info windows, and `MapClicked`.

**Learn more**
