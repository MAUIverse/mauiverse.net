The **August 2026** standup focuses on release news that matters for .NET 11 readiness, plus ongoing quality work across popups and media playback.

### What you'll learn

- `CommunityToolkit.Maui` **15.0.0** and `CommunityToolkit.Maui.Markup` **8.0.0** — removing internal MAUI API usage so Toolkit packages stay compatible with .NET 11
- `CommunityToolkit.Maui` **14.2.2** bug fixes for popup close race conditions and Windows folder picker initial path
- Investigation into iOS/macOS `MediaElement.MediaOpened` firing before `AVPlayerItem` is `ReadyToPlay`
- Progress on `TryShowPopupAsync` / `TryClosePopupAsync` and related popup concurrency APIs
- Community Q&A with the Toolkit maintainers

Watch this one if you are planning a .NET 11 upgrade path or need the latest Toolkit shipping and investigation status.
