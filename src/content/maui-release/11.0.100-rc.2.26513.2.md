# .NET MAUI 11.0.0-rc.2 Release Notes

.NET MAUI 11.0.0-rc.2 introduces significant improvements across all platforms with a focus on quality, performance, and developer experience. This release includes 301 commits with various improvements, bug fixes, and enhancements.

## Workloads

**Workload Set:** [Microsoft.NET.Workloads.11.0.100-rc.2 @ 11.0.100-rc.2.26513.2](https://www.nuget.org/packages/Microsoft.NET.Workloads.11.0.100-rc.2/11.100.0-rc.2.26513.2)

## Installation

```bash
dotnet workload update --version 11.0.100-rc.2.26513.2
# Or install specific workloads
dotnet workload install maui ios maccatalyst android --version 11.0.100-rc.2.26513.2
```

### Recommended Tools:
- Xcode: 27.0
- Java JDK: 21.0.9
- Android API-37.0
