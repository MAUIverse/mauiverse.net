# .NET MAUI 10.0.120 Release Notes

**Release source:** [6aca5366139ed0e1cd05cca3e32b6a887d5a8dd0](https://github.com/dotnet/maui/commit/6aca5366139ed0e1cd05cca3e32b6a887d5a8dd0)
