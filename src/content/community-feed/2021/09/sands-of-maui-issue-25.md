Sam Basu's *Sands of MAUI* #25 is a curated stop for developers tracking .NET MAUI GA Timeline, .NET 6 RC1 Release, .NET MAUI Migration, Prism.MAUI Update. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI GA Timeline** — Forms into a modern cross-platform framework for targeting mobile and desktop apps from single codebase. .NET MAUI is also a big promise, and cross-platform tooling has lots of dependencies from various teams—VS engineering, XAML experience, MAUI folks and, of course, bits from Apple and Google.
- **.NET 6 RC1 Release** — .NET platform runtimes, libraries and SDKs. .NET Core, while providing a single SDK for consistent developer experience. .NET MAUI Preview 8 and Visual Studio 2022 Preview 4. .NET 6 journey.
- **.NET MAUI Migration** — .NET MAUI, the last release was Preview 7 and now we have Preview 8. .NET MAUI, what would be the migration story from Preview 7 to 8 ? Turns out, this is not so difficult and there are formal guidelines in place.
- **Prism.MAUI Update** — Forms? MAUI to move the goodness forward. MAUI forward. .NET MAUI Preview 8—give it a spin and chime in.
- **ASP.NET Core Updates** — .NET MAUI, web technologies are welcome in native mobile/desktop apps—Blazor leads the way with Blazor Hybrid apps and the BlazorWebView component. .NET Core updates —many of these have interesting connotations when sharing code with web technologies like Blazor, JavaScript or SPA apps.
