Gerald Versluis takes on .NET MAUI on .NET Rocks in this podcast conversation, published as “.NET Rocks!”. The source connects the core idea to the APIs, project structure, and platform behavior developers need to understand before using it in a real .NET MAUI app.

## What you'll learn

- **Visual structure** — how the page or control is composed from .NET MAUI layout primitives
- **State and interaction** — the bindings, gestures, commands, and visual states that make the UI respond
- **Adaptive behavior** — how the design handles screen sizes, themes, and platform conventions
- **Reusable implementation** — patterns for turning the example into maintainable app components

Listen to the full episode for the complete discussion and the guests’ perspective on where the technology is heading.
