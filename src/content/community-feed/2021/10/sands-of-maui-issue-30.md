Sam Basu's *Sands of MAUI* #30 is a curated stop for developers tracking .NET MAUI Preview 9 Overview, .NET Conf, .NET MAUI Community Toolkit, ASP.NET Core Updates in .NET 6 RC2. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Preview 9 Overview** — .NET MAUI Preview 9 overview video . Forms and the newest UX hotness with Borders, Corners and Shadows. Next on the agenda was the optimization of Android startup times and covering news of community UI component suites aimed at developer productivity.
- **.NET Conf** — .NET Conf . .NET Conf is a fully virtual conference happening November 9-11, 2021—streamed live non-stop for three days. .NET 6 with LTS support and developer tooling supporting the new release. While Microsoft folks will cover the big news, there are lots of awesome community speakers lined up to carry forward the excitement.
- **.NET MAUI Community Toolkit** — .NET MAUI developer experience. .NET MAUI Community Toolkit —with detailed steps and sample apps. .NET 6. .NET MAUI Community Toolkit is here to help.
- **ASP.NET Core Updates in .NET 6 RC2** — .NET Core. .NET MAUI developers for two reasons— Blazor that can be used toward Desktop apps and Minimal API updates that can power backend services. .NET Core updates , notably Native dependency support for Blazor WebAssembly apps and Minimal APIs.
- **macOS Monterey** — At a recent Apple Unleashed event, Apple announced new M1 Pro and M1 Max chips that will power the shiny new MacBook Pro laptops. Along with new hardware comes the new macOS software update—nicknamed macOS Monterey , available for download beginning October 25, 2021.
