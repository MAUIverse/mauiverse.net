Sam Basu's *Sands of MAUI* #27 is a curated stop for developers tracking XamExpertDay Fun, Visual Studio 2022 for Mac, MVVM Design Pattern, Telerik UI for .NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **XamExpertDay Fun** — .NET MAUI with the developer community. Thus was born XamExpertDay —an all virtual event for the 2021 edition put together by the crew & few more volunteers. .NET MAUI developers. Kudos to everyone involved!
- **Visual Studio 2022 for Mac** — .NET MAUI development on MacOS has been mostly CLI-driven. .NET MAUI. We may not quite be there yet, but Jordan Matthiesen and team have taken the first steps. .NET IDE with a refreshed, fully native macOS UI. .NET 6 & C# 10 development.
- **MVVM Design Pattern** — This one is an oldie, but goldie—more like evergreen developer content. .NET MAUI. An architectural design pattern that is very popular and battle-tested for such codebases is MVVM —the Model-View-ViewModel pattern.
- **Telerik UI for .NET MAUI** — .NET MAUI apps. .NET MAUI Preview 8. Amongst the new UI components are the ubiquitous full-featured ListView , NumericInput , Dock & Wrap Layouts , along with re-done sample app. Oh, and one more thing—there is MacOS support now for most UI controls, in addition to iOS, Android and Windows.
- **Azure IoT on .NET MAUI Podcast** — .NET MAUI podcast saw Matthew Soucoup host an interesting conversation on all things Azure IoT , with Stefan Wick, Rido Minguez Pablos and Ben Buttigieg from the team joining in as guests. .NET developers to connect their smart devices to the cloud for building intelligent solutions.
