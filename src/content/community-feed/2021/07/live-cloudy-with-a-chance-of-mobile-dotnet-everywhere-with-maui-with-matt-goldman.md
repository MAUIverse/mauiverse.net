Matt Goldman takes on .NET Everywhere with MAUI in this ~1.5-hour video, published as “LIVE: Cloudy with a Chance of Mobile: .NET Everywhere with MAUI with Matt Goldman”. The source connects the core idea to the APIs, project structure, and platform behavior developers need to understand before using it in a real .NET MAUI app.

## What you'll learn

- **Visual structure** — how the page or control is composed from .NET MAUI layout primitives
- **State and interaction** — the bindings, gestures, commands, and visual states that make the UI respond
- **Adaptive behavior** — how the design handles screen sizes, themes, and platform conventions
- **Reusable implementation** — patterns for turning the example into maintainable app components

Watch the full session for the complete walkthrough, demonstrations, and links shared by the presenter.
