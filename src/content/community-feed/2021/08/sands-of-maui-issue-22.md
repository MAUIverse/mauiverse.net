Sam Basu's *Sands of MAUI* #22 is a curated stop for developers tracking .NET MAUI Tooling, .NET MAUI Migration with Upgrade Assistant, Xamarin.Forms Behaviors in .NET MAUI, Minimal APIs in ASP.NET. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Tooling** — .NET developers to target iOS, Android, Windows and MacOS—there are lots of moving pieces that make up the technology stacks. .NET MAUI team, XAML tooling team and Visual Studio engineering. .NET MAUI ahead of RC releases.
- **.NET MAUI Migration with Upgrade Assistant** — This might be an oldie, but goldie. .NET MAUI Community Standup —and had special guest Sweekriti Satpathy . .NET MAUI. .NET Upgrade Assistant as a first step of the migration—this is what the future will look like.
- **Xamarin.Forms Behaviors in .NET MAUI** — Forms developers are used to the idea of Behaviors—the little pieces of UI functionality that you attach/detach from UI components without changing their fundamentals. .NET MAUI? .NET MAUI . .NET MAUI code.
- **Minimal APIs in ASP.NET** — .NET MAUI apps will not live in silo—they would need to be backed with data and services from the backend. If you are a solo developer or working on a team that builds a robust backend for your apps, you would have to know a thing or two about building APIs.
- **Blazor Hotness in .NET 6** — .NET 6—Blazor is bringing some coolness as well. .NET 6 —Dynamic Components, Hot Reload, AOT Compilation for Blazor WASM and more. .NET MAUI provides the perfect bootstrapping and makes modern WebViews available, so Blazor can do its thing.
