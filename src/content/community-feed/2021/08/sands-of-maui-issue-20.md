Sam Basu's *Sands of MAUI* #20 is a curated stop for developers tracking .NET MAUI Preview 7, .NET MAUI Preview 7 Overview, .NET MAUI Preview 7 Setup, .NET MAUI Debugging in VS Code. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Preview 7** — .NET MAUI release—Preview 7 this time. David Ortinau detailed all the goodies included in Preview 7, starting with the new Layout system—the LayoutManager helps organize the visual tree and is optimized for consistency, performance and maintainability.
- **.NET MAUI Preview 7 Overview** — .NET MAUI release is followed by an awesome Gerald Versluis YouTube video . .NET MAUI Preview 7. .NET 6 and now has support in the latest Visual Studio 2022 bits. .NET MAUI Blazor apps.
- **.NET MAUI Preview 7 Setup** — .NET MAUI but haven't started tinkering with it yet? .NET MAUI Preview 7 bits. .NET MAUI basics, but more importantly walks you through the development machine setup—both on a Mac with CLI/VS Code and then on Windows with VS 2022 Preview 3.
- **.NET MAUI Debugging in VS Code** — .NET MAUI on a Mac? Sure you have CLI tools, but the build/debug process requires a bit of manual setup. .NET Mobile extension to automate the process. .NET MAUI. Even if you are not using the MVU way, as Vijay points out—the Comet extension does actually help in automating the build/change/debug cycle with VS Code running on a Mac.
- **.NET MAUI Community Toolkit Standup** — Forms development. .NET MAUI. .NET MAUI Community Toolkit standup —a monthly open discussion with some of the core contributors on latest news and roadmap updates. And the best smile on the internet award unanimously goes to Brandon Minnick .
