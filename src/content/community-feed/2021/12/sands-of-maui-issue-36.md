Sam Basu's *Sands of MAUI* #36 is a curated stop for developers tracking .NET Podcast App, .NET MAUI Community Standup, Customizing .NET MAUI Controls, Angular with.NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET Podcast App** — .NET content from Microsoft folks and speakers from all around the world. .NET 6. .NET Podcast app now open sourced . .NET MAUI app with Blazor and Azure Container Apps goodness baked in—a nicely architected codebase for developers to explore.
- **.NET MAUI Community Standup** — .NET MAUI Community Standup with an epic beginning and with special guest THE Jonathan Dick . .NET MAUI/Blazor/C# and recapping exciting community blog updates. Forms—the present reality that isn't shabby at all with latest service release and lots of community PRs.
- **Customizing .NET MAUI Controls** — .NET MAUI provide abstraction over native UI across platforms—developers get to write C#/XAML that gets rendered as native controls on each respective platform. What if you wanted to customize the look and feel or some behavior of the native UI, perhaps on a per platform basis?
- **Angular with.NET MAUI** — .NET MAUI is a great story—brings in the goodness of web to native mobile/desktop apps. However, what if you had investments in JavaScript, like in modern frontend apps with JS SPA frameworks?
- **.NET MAUI Community Toolkit Unpacked** — .NET MAUI Community Toolkit but haven't given it a spin yet? .NET MAUI Community Toolkit and how to get started using it. .NET MAUI developer experience with Extensions, Behaviors, Converters, UI Elements and more—nothing stopping you from being more productive.

Open the original roundup to follow the links, see the supporting examples, and explore the referenced community work in more depth.
