A spinner tells the user to wait. A skeleton shows the shape of the screen that is coming. Horus Software's Skeleton 3.0 page is the tour of their .NET MAUI loading library: two attached properties to start, no other dependencies, and a playground for the animations.

## What you'll learn

- **What you are adding** — `HorusStudio.Maui.Skeleton` 3.0 for .NET 8, 9, and 10, with Skeleton 2.0 still covering .NET 6 and 7. MIT licensed, and past 600K downloads across both packages
- **How a screen opts in** — placeholders bound to a bool such as `IsBusy`. Lists need a few rows seeded before the data arrives, and the sample markup is meant to be copied and adapted
- **Animations in 3.0** — Shimmer, Aurora, and Tint join Fade, Beat, horizontal shake, vertical shake, and none. Direction and sweep colors are new in this version; interval and a parameter still drive the older effects
- **Layouts to start from** — Feed, Profile, a card grid, Article, Chat, and Checkout, shown in XAML and C#
- **An agent skill** — one Markdown file at `skills.horus.com.uy/skeleton` for Claude Code, Codex, Copilot, and Cursor, so an agent can write placeholders for a view you already have, using your theme colors

Open the page, flip through the playground, and read the skill file before you point an agent at a view.
