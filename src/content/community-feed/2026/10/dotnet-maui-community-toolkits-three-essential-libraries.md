Three Community Toolkits, and a talk from the person who created one of them. Recorded at NDC Oslo, Brandon Minnick walks through the libraries he expects .NET MAUI developers to reach for when the goal is shorter, more readable code.

## What you'll learn

- **MVVM Community Toolkit** — source generators that write the boilerplate MVVM code, so the app code stays the part you actually meant to write
- **.NET MAUI Community Toolkit** — the converters, behaviors, and views he treats as essentials, including `DrawingView`, `Popup`, and `MediaElement`
- **.NET MAUI Markup** — building the same UI in C# instead of XAML, when a fluent markup style is the faster read
- **How he wants them used** — best practices across the three, and the features he puts a spotlight on rather than a tour of every API

Watch the full ~46 minute session for the live walkthrough. If you are not using the toolkits yet, this is the talk he gives to change that.
