This one follows the format Leomaris Reyes has used for her other UI replications: break the design into numbered blocks, explain each with code, and show a screenshot after every step. The target is a Dribbble design for a children's app that teaches animals, built as an animal list and a detail screen.

The main screen starts with a popular-animals block, which has a title, a search button and a horizontal list. An animal-types block follows. The detail screen then adds a header and a key-facts block. Along the way she uses `Grid` layouts, rounded elements with the Telerik `RadBorder`, and dynamic lists with the Telerik CollectionView.

It's a gentle exercise if you want to practice turning a mockup into XAML. As with her earlier posts, the Telerik controls need a license or trial.
