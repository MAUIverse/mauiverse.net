AI can write your XAML and C#, but it can't tell whether a button is actually visible on screen. This demo-driven session closes that gap by giving the assistant a view of the running app. Starting with an existing MAUI application, Gerald Versluis shows DevFlow and an interactive mobile canvas connecting GitHub Copilot to the app.

From there the session moves through a feedback loop:

- **Inspect the UI** and give the assistant context about specific controls
- **Interact with the app**, then use logs and runtime information to investigate problems
- **Make targeted code changes** and replay user workflows to check the results

Along the way Gerald explains where MCP fits and what these experimental tools can and can't do, with a reminder that developer judgment still matters. If you use an AI assistant on MAUI projects, it's a useful look at moving from generated code to verified results.
