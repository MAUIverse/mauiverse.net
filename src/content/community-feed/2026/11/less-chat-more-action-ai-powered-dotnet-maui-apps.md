A chat box is easy to add. Making it useful means the assistant can act inside your app. Gerald Versluis uses a conference companion app as the example: users ask it to find sessions, update their agenda or open the right screen, and the interface reflects the change.

The session shows how to expose application actions as AI-callable tools with Microsoft.Extensions.AI and experimental tooling from .NET MAUI Labs, reuse existing services and view models, and keep the conversation and the UI working from the same application state.

It also looks at where to draw the line: validating requests, asking for confirmation before destructive actions, and handling requests the assistant can't fulfill. If you're thinking about an assistant that does more than talk, while keeping users in control, this session gives you practical patterns to start from.
