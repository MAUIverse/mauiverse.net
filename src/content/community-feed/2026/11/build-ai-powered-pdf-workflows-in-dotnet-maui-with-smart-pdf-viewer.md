Viewing a PDF is rarely the whole job. Users also need to find a clause in a long agreement, remove personal details before sharing, or fill out a form from information they've already copied. Syncfusion's Smart PDF Viewer for .NET MAUI puts AI assistance for those tasks inside the viewer itself.

The post frames it around a customer onboarding app and walks through three features:

- **AI Assistant:** summarize long documents and ask questions about their content
- **Smart Redaction:** detect sensitive details such as names, email addresses and phone numbers that should be redacted
- **Smart Form Fill:** extract values from copied text and fill the matching PDF form fields

It also covers the provider side, using Azure OpenAI, so you can see where the AI service plugs in. The getting-started section runs from creating the project and installing NuGet packages through configuring the Syncfusion services, adding the viewer, enabling each feature and registering the license.

Android, iOS, macOS and Windows are supported. If you already use Syncfusion controls, or you're evaluating AI-assisted document features for a MAUI app, the setup steps are the quickest way to judge how much code it takes.
