The Shiny.NET ecosystem got a big drop, and this GoneDotNet session is the guided tour. Jon Dick and Allan Ritchie walk through the newest libraries and demo what they unlock for .NET MAUI and Blazor developers.

### What you'll learn

- **Shiny Controls 1.0** — the cross-platform control suite spanning native MAUI and real Blazor components
- **HTTP server for MAUI** — running an in-app HTTP server and where that's useful
- **mDNS discovery** — the discovery library for finding services on the local network
- **Why they built them** — the motivation and design decisions behind each library, with live demos

Watch the full ~1.5 hour session for the demos and links to docs across the Shiny libraries.
