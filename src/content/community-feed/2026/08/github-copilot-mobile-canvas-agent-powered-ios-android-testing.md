Mobile testing usually means juggling IDE tools, emulators, and AI chat in separate windows. James Montemagno demos a GitHub Copilot Canvas plugin that pulls iOS simulators and Android emulators into the same canvas where agents can drive them.

## What you'll learn

- **Mobile Canvas plugin** — what the GitHub Copilot mobile device plugin does and where to get it
- **Quick install** — how to add the plugin and start using it in seconds
- **Agent-powered testing** — launching, configuring, and interacting with emulators while AI agents exercise features in real time
- **Unified workflow** — keeping device control and AI-assisted testing in one interface

Watch the full video for the install steps and interactive demo, and grab the plugin at [Redth/mobile-canvas-ghcp](https://github.com/Redth/mobile-canvas-ghcp).
