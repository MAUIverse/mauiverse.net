In this Gone DotNet episode, Jonathan Dick and Allan Ritchie set out to make MAUI Sherpa a single tool for all your mobile needs — setup, build, and deploy — while sharing frank opinions on the current crop of AI coding assistants.

## What you'll learn

- **Sherpa as a one-stop shop** — the plan to add setup, build, and deploy to its dev and debug capabilities
- **Deployment tooling** — early thinking on how to streamline mobile deployment
- **AI model tradeoffs** — hands-on impressions of cost versus value across different coding models
- **DevFlow tips** — using session-analysis skills to feed bugs and workarounds back into MAUI DevFlow

Watch the full episode for the live build work and the ongoing AI tooling debate.
