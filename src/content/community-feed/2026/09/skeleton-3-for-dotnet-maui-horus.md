Horus Software has released Skeleton 3.0, the latest version of its open-source library for showing loading placeholders in .NET MAUI apps. With 600K+ downloads and 450+ GitHub stars, Skeleton lets you turn any existing view into an animated placeholder while data loads.

## What's new

- **New animations** — Shimmer, Aurora, and Tint join the existing set, for seven animation options across six customizable layouts
- **Fine-grained control** — configure direction, sweep colors, and timing intervals to match your app's look
- **Modern .NET support** — targets .NET 8, 9, and 10 with zero dependencies (Skeleton 2.0 remains available for earlier versions)
- **AI skill for coding agents** — point Claude Code, Copilot, Cursor, or Codex at an existing view and let it generate the skeleton using your app's theme colors
- **Free and MIT-licensed** — source on [GitHub](https://github.com/HorusSoftwareUY/Xamarin.Forms.Skeleton), package on [NuGet](https://www.nuget.org/packages/HorusStudio.Maui.Skeleton)
