Recreating a finished design is one of the quickest ways to find the gaps in your XAML, and Leomaris Reyes picks a room-subletting screen to do it. The design is split into three labelled blocks (header and background, description, footer), and each block gets its own screenshot and code so you can check your progress as you go.

The header block sets up the foundation: a single-column Grid that layers a full-bleed background image under a second Grid holding the labels and action buttons. The description block covers the room details, the price, a contact button and the Telerik Rating control, which is the component Leomaris builds the article around.

The code is simple and the explanations are friendly, so it suits anyone still getting comfortable with overlapping layouts. Because it uses Telerik UI for .NET MAUI, you'll need the package and a license or trial to follow along exactly.
