The first screens a person sees in your app are usually the account ones, and they're easy to under-design. Leomaris Reyes takes a clean login and register concept and builds two pages from it, working through each design block in order.

The welcome page layers a white, rounded container over a header image with a negative top margin, using the Telerik `RadBorder` for the corners. From there the post adds the welcome text, a gradient login button and a create-account option. The second page reuses the same structure for the sign-up form, built with the Telerik DataForm and a small model class, and finishes with a divider and social sign-in buttons.

The pattern repeats across both pages, so it's a useful reference for the overlap effect in particular. As with the author's other UI replications, the Telerik controls need a license or trial.
