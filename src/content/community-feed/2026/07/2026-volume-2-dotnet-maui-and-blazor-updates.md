Syncfusion's short release overview highlights targeted improvements for building smarter, more productive .NET MAUI and Blazor interfaces. It is a fast visual index of the features added across AI Assist, grids, and charts.

## What you'll learn

- **Resizable prompts in .NET MAUI** — give users more room to compose requests inside `AI AssistView`
- **Safer DataGrid editing** — add undo and redo so users can recover from changes without custom history plumbing
- **Clearer chart hierarchies** — organize Cartesian Chart axes with multilevel categorization for more intuitive data presentation
- **Inline AI for Blazor** — bring focused assistance directly into the user's current workflow with the new Inline AI Assist component
- **Guided chart creation** — use the interactive Blazor Chart Wizard to move from data selection through a configured visualization
- **Richer AI interactions** — capture prompts through speech input and let users regenerate responses in Blazor `AI AssistView`
