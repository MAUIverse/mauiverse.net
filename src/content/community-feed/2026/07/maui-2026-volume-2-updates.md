The 2026 Volume 2 release brings a focused set of enhancements to Syncfusion's .NET MAUI controls, with a clear theme: smarter AI-driven experiences and less friction for everyday data-heavy screens. Here's a tour of what's new.

## What's new

- **AI AssistView** — an agent picker for switching between assistants, conversation management, and a set of AI chat experience enhancements to make in-app assistants feel more polished
- **Cartesian Charts** — point color mapping to encode data by color, plus multilevel axis labels for richer categorization
- **DataGrid** — undo/redo support, multi-row dragging, interactive row resizing, and a built-in search UI
- **ListView** — a built-in filtering UI so users can narrow large lists without custom plumbing
- **TreeView** — built-in checkboxes for selection and hierarchical toggling

Each feature is aimed at cutting the boilerplate you'd otherwise write yourself. Read the full post for the code snippets, screenshots, and configuration details, then grab the release to try the updates in your own .NET MAUI project.
