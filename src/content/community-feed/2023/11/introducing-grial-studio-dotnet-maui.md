At .NET Conf 2023, Pablo Germano and Diego Rivero from UXDivers launch Grial Studio — a Visual Studio extension that puts production-ready Grial templates, themes, controls, and icons a few clicks away inside your existing .NET MAUI workflow.

## What you'll learn

- **What Grial Studio is** — a design-and-productivity layer on top of Grial UI Kit that lives inside Visual Studio
- **Scaffolding pages fast** — pulling free templates and resources into a new or existing project instead of blank XAML
- **Themes without hand-tuning** — using the integrated theme manager to brand an app without rewriting styles from scratch
- **Icon fonts in the IDE** — browsing and dropping SVG icon fonts straight into XAML
- **Never start UI from zero** — how the library is meant to assist at every stage, not only greenfield kicks

Watch the session to see a .NET MAUI app come together in record time with the tools that shipped at the conference.
