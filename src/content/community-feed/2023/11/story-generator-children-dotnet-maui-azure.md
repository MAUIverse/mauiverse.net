Héctor Pérez’s .NET Conf 2023 demo walks through a cross-platform children’s storytelling app: .NET MAUI on the client, Azure OpenAI for story and image generation, and Azure Text to Speech for narration — wrapped in UI details that make the experience feel magical.

## What you'll learn

- **End-to-end architecture** — MAUI client plus an ASP.NET Core API so keys stay off the device
- **Azure OpenAI via Semantic Kernel** — generating story text and images for younger audiences
- **Text to Speech storytelling** — turning generated content into spoken narration
- **Kid-friendly UI craft** — parallax, animated gradients, custom SkiaSharp playback chrome, and loading popups
- **Practical packaging tips** — how the five build steps fit together into a shippable demo

Watch the session for the live walkthrough, then dig into Héctor’s write-up if you want the source-level follow-along.
