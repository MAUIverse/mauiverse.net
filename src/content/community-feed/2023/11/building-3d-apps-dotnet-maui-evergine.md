Want a product viewer or indoor map that isn’t stuck as a flat image? In this .NET Conf 2023 session, Javier Suárez and Jorge Cantón demonstrate Evergine’s industrial 3D engine running inside .NET MAUI, including the templates and `EvergineView` control that wire scenes into XAML pages.

## What you'll learn

- **Why 3D in MAUI matters** — e-commerce models, mall maps, and other experiences the community kept requesting
- **Evergine + MAUI integration** — how the engine’s canvas control sits inside a normal MAUI layout
- **Project templates** — spinning up a MAUI profile from the Evergine Launcher with assets managed in Evergine Studio
- **Cross-platform deployment** — building the same 3D-enabled app for mobile and desktop targets
- **Where to go next** — links to Evergine docs and the related .NET Blog walkthrough

Watch the full talk for the live demo path from empty template to interactive 3D content in a MAUI app.
