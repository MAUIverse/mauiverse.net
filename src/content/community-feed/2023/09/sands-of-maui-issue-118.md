Sam Basu's *Sands of MAUI* #118 is a curated stop for developers tracking .NET MAUI for .NET 8, Telerik UI, Gaming with .NET MAUI, Charts with .NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI for .NET 8** — .NET 8 has been cooking and is scheduled to hit prime time in November 2023. .NET 8 has reached Release Candidate 1 status. .NET 8 Release Candidate 1 is now out . .NET 8 now carries a go live license—developers should have the confidence to use the release bits for production applications.
- **Telerik UI** — .NET MAUI, developers can target mobile and desktop form factors from a single shared codebase. .NET MAUI app development, however, means catering to different platform experiences and building complex yet performant UI that renders consistently across devices.
- **Gaming with .NET MAUI** — .NET cross-platform development stack, allowing developers to reach mobile and desktop form factors from a single shared codebase. .NET MAUI—framework maturity, stable tooling and welcoming web developers. .NET MAUI .
- **Charts with .NET MAUI** — Data is everywhere. Data is plentiful. It is easy to get overwhelmed with the quantity of data in modern digital lives—the only saving grace is visualization. Data visualization is the only way to make sense of data and be able to see trends—it is how users of modern apps expect to consume data.
- **Grid with .NET MAUI** — .NET MAUI provides a solid foundational framework and stable tooling, real-world app development often demands a lot from developers—some UI empowerment is welcome. Most modern apps need showing a list of things—tabular data needs proper UI visualization and users need lots of features to work with the data.
