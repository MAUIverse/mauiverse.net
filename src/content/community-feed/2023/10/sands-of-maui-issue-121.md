Sam Basu's *Sands of MAUI* #121 is a curated stop for developers tracking .NET MAUI for .NET 8, Telerik UI, 3D Apps with .NET MAUI, Xcode Versions. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI for .NET 8** — .NET 8 has been cooking and is scheduled to hit prime time in November 2023. .NET 8 has reached Release Candidate 2 status. .NET 8 Release Candidate 2 is now out . .NET 8 now carries a go-live license—developers should have the confidence to use the release bits for production applications.
- **Telerik UI** — .NET MAUI, developers can target mobile and desktop form factors from a single shared codebase. .NET MAUI app development, however, means catering to different platform experiences and building complex yet performant UI that renders consistently across devices.
- **3D Apps with .NET MAUI** — Visualization is everything for modern apps, and 3D representation instead of static images is the next frontier. Be it browsing for products, navigating maps or other immersive experiences, 3D simply makes everything better.
- **Xcode Versions** — Xcode is Apple's popular integrated development environment (IDE) for macOS, used to develop software for macOS, iOS, iPadOS, watchOS, tvOS and visionOS. .NET MAUI apps are essentially native apps with layers of abstraction.
- **ComboBox for .NET MAUI** — .NET cross-platform development—a single shared codebase allows reach into mobile/desktop platforms. .NET MAUI should be the same way—abstracted APIs prevent developer learning curves, while rendering native UI across iOS/Android/Windows/macOS.
