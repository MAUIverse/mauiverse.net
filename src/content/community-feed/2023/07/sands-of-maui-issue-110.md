Sam Basu's *Sands of MAUI* #110 is a curated stop for developers tracking .NET MAUI Update, .NET MAUI on VS Code, Hands-On with VS Code Extension, .NET MAUI Handler Mappings. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Update** — .NET 8. .NET 8 Preview 6 is now out. .NET 8 Preview 6, along with tooling updates . .NET 8 Preview 6 introduces Native AOT (ahead-of-time compilation) for iOS—this opt-in preview feature enables 30-40% reduction in app sizes compared to Mono and better app performance.
- **.NET MAUI on VS Code** — .NET development and developers have stable tooling in the form of Visual Studio for both Windows/macOS. .NET MAUI development in chill mode—Command Line tools and light-weight editors for the win. Visual Studio Code continues to be the uber-popular light-weight code editor, working consistently across Windows/macOS/Linux.
- **Hands-On with VS Code Extension** — .NET MAUI more accessible to all types of developers. .NET MAUI on Windows, macOS and Linux. .NET MAUI Support in VS Code in action, this video is just the answer. .NET MAUI extension in VS Code. .NET MAUI workloads installed—the Extension can help new developers get the requisite bits installed.
- **.NET MAUI Handler Mappings** — .NET MAUI is more than a UI framework—it’s a collection of loosely coupled abstractions spanning the UI layer all the way down to the platform runtime level. .NET MAUI provides or create their own. Forms, but with this flexibility comes potential confusion about where to implement and keep Handler customizations.
- **.NET MAUI Development Hardware** — .NET cross-platform development stack—a unified codebase provides abstractions to help developers reach mobile/desktop platforms seamlessly. .NET MAUI, however, is a big one involving varied target platforms and complicated technology stacks.
