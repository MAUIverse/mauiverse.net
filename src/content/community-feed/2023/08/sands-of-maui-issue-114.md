Sam Basu's *Sands of MAUI* #114 is a curated stop for developers tracking CoPilot for .NET MAUI, Calendar UI for .NET MAUI, .NET MAUI for .NET 8, DockLayout for .NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **CoPilot for .NET MAUI** — GitHub Copilot is an AI-powered pair programmer extension for Visual Studio that provides developers with context-aware code completions, suggestions and even entire code snippets. This powerful tool helps developers write code more efficiently, reduce the time spent on repetitive tasks and minimize errors.
- **Calendar UI for .NET MAUI** — .NET cross-platform development, serious developers know the need to augment the UI stack—no point trying to recreate the wheel when engineering is expensive. .NET MAUI can help—the most comprehensive UI component library for polished performant UI controls that work seamlessly across mobile and desktop.
- **.NET MAUI for .NET 8** — .NET 8 has been cooking and is scheduled to hit prime time in November 2023. .NET 8 Preview 7 is now out. .NET MAUI MAUI Preview on Visual Studio for Mac . .NET MAUI workloads. But why should developers on macOS miss out on the fun?
- **DockLayout for .NET MAUI** — .NET MAUI packs a lot as a developer framework—a unified stack with stable tooling to build native cross-platform apps for mobile/desktop form factors. Real world apps, however, demand a lot from developers—UI needs, boilerplate code and platform abstractions.
- **Paddle Boarding in MAUI** — .NET cross-platform development stack, allowing developers to reach mobile and desktop form factors from a single shared codebase. .NET MAUI—framework maturity, stable tooling and welcoming web developers. .NET 8—issues getting fixed and developer productivity being improved.
