Sam Basu's *Sands of MAUI* #109 is a curated stop for developers tracking Saving Files with Toolkit, UI for Better Apps, Authentication with Okta, Telerik Blazor UI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **Saving Files with Toolkit** — Modern mobile/desktop apps often deal with writing files to disk, but developer perception suggests that this is often tricky. Saving a file to disk comes down to platform implementations, and there are obviously differences between Windows/macOS, as well as iOS/Android—this can be tedious for developers.
- **UI for Better Apps** — The world runs on YouTube. .NET MAUI, most of us are in consumption mode when on YouTube. There are a handful who dare to be content creators, and for them, YouTube numbers matter. Wouldn't it be cool if there was a cross-platform app that made sense of YouTube statistics?
- **Authentication with Okta** — For any serious mobile/desktop app, user authentication is often the first step before using the app/services—it's the way to know whether the user is indeed who they say they are. User authentication can be messy business, though—the security stakes are high and the threat landscape is always changing.
- **Telerik Blazor UI** — .NET developers have understandably been excited about Blazor—a modern web framework allowing for C# code front and back. Blazor can run server-side or entirely client-side with WebAssembly, and the Blazor component/rendering model inspires confidence with stability and extensibility.
- **MVVM Architecture** — The Model-View-ViewModel (MVVM) design pattern ensures a well-defined separation between software layers—the View representing the XAML user interface; the Model encompassing the underlying data and the ViewModel serving as the intermediary between the other two.
