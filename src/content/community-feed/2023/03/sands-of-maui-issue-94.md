Sam Basu's *Sands of MAUI* #94 is a curated stop for developers tracking .NET MAUI Community Standup, .NET MAUI UI with StackLayout, Responsive Layouts in .NET MAUI, .NET MAUI Community Toolkit. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Community Standup** — .NET MAUI Community Standup and there was much news to share. .NET runtime. .NET MAUI apps being built and running on Windows for ARM based devices. .NET MAUI SDK/tooling. As a special guest, Maddy and David were joined by Jeffrey Stedfast —long-distinguished Xamarin/Linux engineer.
- **.NET MAUI UI with StackLayout** — .NET MAUI is UI abstraction—developers get to define a visual tree in XAML/C# that renders native UI components on respective mobile/desktop platforms. However, there are nuances to how UI elements are placed and arranged within a visual tree, and one of the most common approaches used by developers is a StackLayout.
- **Responsive Layouts in .NET MAUI** — User experience is key for any modern app, particularly for mobile form factors. With small real estate and transient user attention, mobile developers need to do everything possible to impress.
- **.NET MAUI Community Toolkit** — .NET MAUI Community Toolkit has become a beacon of hope. .NET MAUI, including animations, behaviors, converters, effects and helpers. 0 is now released . .NET MAUI. The latest release introduces SemanticOrderView to control the order of visual elements for screen readers—this improves app accessibility directly.
- **From Mono to .NET MAUI** — .NET developers for a day of fun, with in-person audiences in Stockholm and livestreamed online. .NET Rocks did an interesting session to close out the day— From Mono to MAUI: The History of Xamarin . .NET MAUI came to be and there are few better storytellers than Richard.
