Sam Basu's *Sands of MAUI* #105 is a curated stop for developers tracking State of .NET MAUI, Visual Studio Dev Tunnels, Safe Area Layouts, JavaScript with .NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **State of .NET MAUI** — .NET cross-platform development—a single shared codebase powers modern apps on mobile or desktop platforms. .NET MAUI as a product and an ecosystem. .NET MAUI . All eyes were on Build last week—Microsoft’s premier developer conference happened both virtually and in-person in Seattle.
- **Visual Studio Dev Tunnels** — .NET MAUI, do not live in a silo. The reality is client apps often interact with a server-hosted backend service—this could be for data, APIs, authentication or various other needs.
- **Safe Area Layouts** — Modern mobile form factors come with lots of hardware variations—sometimes, there are encroachments into the regular visible screen area. Common examples are rounded device corners, home indicator or camera/sensor housing—the most obvious one being the notch on top of iOS devices.
- **JavaScript with .NET MAUI** — .NET MAUI is a particularly good story—developers get to bring in Blazor goodness for web apps into native mobile/desktop apps, while sharing code and with complete native platform API access. .NET MAUI. David Ortinau did an interesting recorded session for Microsoft Build— Angular and ReactJS for mobile/desktop apps .
- **Animate Windows Apps** — .NET MAUI's cross-platform capabilities, it is sometimes easy to forget that developers are actually building very native apps and all of the platform's capabilities are at the app's disposal. .NET MAUI uses the latest UI/UX framework to reach Windows.
