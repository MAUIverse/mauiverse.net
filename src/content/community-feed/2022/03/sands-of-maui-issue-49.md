Sam Basu's *Sands of MAUI* #49 is a curated stop for developers tracking .NET MAUI Preview 14, .NET MAUI Preview 14 Overview, Inside .NET MAUI Preview 14, Visual Studio 2022 for Mac. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Preview 14** — .NET MAUI Preview 14 is now out. .NET MAUI Preview 14 announcement post. .NET MAUI slowly reaches Release Candidate release status—this release includes a hefty volume of issue resolutions and completed features.
- **.NET MAUI Preview 14 Overview** — .NET MAUI release. The new Menubar for Windows/MacOS should be a very welcome addition for desktop developers—Gerald shows off how to add the Menubar with MenuBarItems / MenuFlyoutSubItems . .NET MAUI offering the entire Essentials package out of the box.
- **Inside .NET MAUI Preview 14** — .NET MAUI Preview 14 ? James Montemagno has just the video ready. James dives straight into code and shares the excitement around the new Menubar UI component for desktop apps—it is now rather easy to add an elaborate menu system for Windows/MacOS apps.
- **Visual Studio 2022 for Mac** — Visual Studio 2022 for Mac is a huge step in the right direction and next milestone aka Preview 7 is here. Jordan Matthiesen wrote up the VS 2022 for Mac Preview 7 announcement post—steady progress is being made towards a high-quality General Availability (GA) release.
- **Visual Studio 25th Anniversary** — Visual Studio recently celebrated its 25th Birthday Anniversary —a quarter of a century is like a million years in the tech industry.
