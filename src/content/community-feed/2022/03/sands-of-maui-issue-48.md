Sam Basu's *Sands of MAUI* #48 is a curated stop for developers tracking .NET MAUI Preview 13 Overview, MVVM Source Generators, StateLayout with Collections, Blazor for Web and Beyond. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Preview 13 Overview** — .NET MAUI Preview 13 has been out for a while and Preview 14 is almost done cooking. .NET MAUI and early adopters are often migrating apps from previous versions. .NET MAUI Preview 13 overview —a holistic look at where things are today and how to move between preview versions.
- **MVVM Source Generators** — .NET MAUI. However, rolling MVVM on your own often means writing a lot of boilerplate code—implementing INotifyPropertyChanged for two-way data binding, defining Commands or writing up an elaborate ViewModelBase class.
- **StateLayout with Collections** — Some time back, Steven Thewissen had created a wonderful plugin which allowed displaying a specific UI component view when the content is in a specific state. This is now a part of the Xamarin Community Toolkit as StateLayout .
- **Blazor for Web and Beyond** — .NET. .NET MAUI. Daniel Roth did a fun session to talk about the state of affairs with Blazor for web and native mobile/desktop apps. .NET 6 and showed off latest tooling with hot reload. While Blazor server-side is a nice way to start for beginners, Blazor WebAssembly has seen a lot of improvements, optimizations and performance tuning.
- **Animations with Lottie** — .NET MAUI. This time, Shaun talks about adding some wow factor to your app— animations with Lottie . Lottie is an animation library that was open-sourced by Airbnb. It parses Adobe After Effects animations to JSON files and renders them natively on iOS/Android.

Open the original roundup to follow the links, see the supporting examples, and explore the referenced community work in more depth.
