Sam Basu's *Sands of MAUI* #44 is a curated stop for developers tracking .NET MAUI Preview 12 Overview, Publish .NET MAUI Apps, React in .NET MAUI, No Worries in .NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Preview 12 Overview** — .NET MAUI Preview 12 has been out for a while and brought along wonderful enhancements like Shell and Dependency Injection. .NET MAUI Preview 12 Overview video from James Montemagno will have a long shelf life. .NET MAUI Shell.
- **Publish .NET MAUI Apps** — Building a mobile app is only half the battle. The other and arguably the more frustrating, error-prone and time-consuming half is pushing our apps to the iOS/Android/Windows App Stores. .NET MAUI apps , particularly Android apps to the Google Play Store.
- **React in .NET MAUI** — .NET MAUI enables developers to embed Blazor web content inside native mobile/desktop apps. However, BlazorWebView is essentially a wrapper that renders the appropriate modern WebView for the given platform and is impartial to web content.
- **No Worries in .NET MAUI** — .NET MAUI. Andreas starts out with how we handle Image resizing and manage Splash Screens today—just not fun to cater to each individual platform. .NET MAUI makes things easier with Resizetizer tool built-in and shared Resources of Fonts, Icons and Splash Screens.
- **Null Pointer Podcast** — Gerald Versluis , Mark Allibone and Steven Thewissen host the Null Pointer podcast—an opinionated podcast on development, tech and every day struggles. Daniel Hindrikes was on as guest for a recent Null Pointers podcast episode to talk about all things Blazor—what's happening with Blazor today and what lies ahead tomorrow.
