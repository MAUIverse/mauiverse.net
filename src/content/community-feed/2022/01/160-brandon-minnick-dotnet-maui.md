Brandon Minnick discusses the wider .NET MAUI landscape in this episode of the *No Dogma Podcast*. The conversation connects the framework’s cross-platform model with the tooling, project structure, and platform behavior developers need to understand before adopting it.

## What you'll learn

- **Cross-platform model** — how .NET MAUI brings shared application code and native platform capabilities together
- **Developer workflow** — the tooling and project structure that shape day-to-day development
- **Platform considerations** — the differences developers still need to account for across target platforms
- **Practical tradeoffs** — the factors to consider when deciding where .NET MAUI fits

Listen to the full episode for the complete discussion and the guests’ perspective on where the technology is heading.
