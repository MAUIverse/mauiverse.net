The .NET MAUI Community Toolkit has become an essential plugin for many .NET MAUI apps. At .NET Conf 2022, Gerald Versluis covers where it came from, what it offers today, and how to start using it in your own projects.

## What you'll learn

- **A bit of history** — how the Community Toolkit(s) evolved from their Xamarin roots
- **What's in the toolkit today** — the behaviors, converters, and helpers that save you from reinventing them
- **Getting started** — the quickest path to adding the toolkit to a .NET MAUI project

Watch the full session for the walkthrough and to see the toolkit's capabilities in action.
