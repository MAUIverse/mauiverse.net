Sam Basu's *Sands of MAUI* #82 is a curated stop for developers tracking .NET MAUI for Native Apps, .NET MAUI in Visual Studio for Mac, .NET 7 Features, Xamarin to .NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI for Native Apps** — .NET MAUI is simple—enable developers to build native, cross-platform desktop/mobile apps all on one framework and from a shared codebase. .NET to build solid native apps has not changed. .NET MAUI to build native no-compromise apps .
- **.NET MAUI in Visual Studio for Mac** — .NET and aims to be platform-agnostic as to how developers are building the apps. .NET MAUI tooling for developers on Windows has been somewhat better than that on macOS, mostly because Visual Studio for Mac went through a big UI overhaul.
- **.NET 7 Features** — .NET 7 is here and ready for developers to build production apps. .NET MAUI, Containerization, Cloud Native, Performance improvements, ARM 64 support and much more. .NET 7 . .NET MAUI should make things worth it. .NET Core, in addition to Minimal API improvements.
- **Xamarin to .NET MAUI** — .NET MAUI to go cross-platform. .NET MAUI . .NET MAUI. With Xamarin support stretching till May 2024, there may not be a huge rush to migrate, but developers should start thinking now and take note of where things stand in their code base.
- **MAUI App Accelerator** — .NET MAUI, the ecosystem is growing and as are the variety of tools/patterns/features/libraries that help. .NET MAUI project should get off on a solid starting point, have requisite tools at their disposal and set up for success with appropriate coding patterns.
