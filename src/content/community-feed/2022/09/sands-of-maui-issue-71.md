Sam Basu's *Sands of MAUI* #71 is a curated stop for developers tracking .NET MAUI Community Standup, Maps in .NET MAUI, .NET MAUI Menu Bar, .NET MAUI Learning Challenge. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Community Standup** — .NET MAUI developers. .NET 7. Maddy started off the show, surrounded by packing boxes from her new home—and covered a variety of content pieces from the developer community. .NET MAUI apps. .NET MAUI now exposes plenty more contextual events like `Loaded`, `Unloaded` and `OnNavigatedTo` across page/window lifecycles.
- **Maps in .NET MAUI** — .NET MAUI is almost reaching prime time—yes, Maps! Mobile and desktop developers often have the need to integrate maps into applications—high fidelity platform-native maps are invaluable to any apps needing geolocation support.
- **.NET MAUI Menu Bar** — .NET MAUI apps is a first-class citizen—your cross-platform app is meant to run on Windows and MacOS seamlessly. Desktop app users, however, have a different set of UX and navigation expectations.
- **.NET MAUI Learning Challenge** — .NET MAUI and earn some awesome stickers. Developer interest has been high, and so far over 400 people have joined the learning challenge. .NET MAUI Cloud Skills Challenge —folks now have till September 30 to finish the challenge.
- **.NET MAUI @ DevReach** — DevReach has been the premier developer conference in Eastern Europe for over a decade now. DevReach is back on for 2022 as a part of Progress360 in post-pandemic mode with both in-person and online experiences—and for the first time, coming stateside to Boston, Mass.
