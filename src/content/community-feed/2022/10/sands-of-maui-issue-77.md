Sam Basu's *Sands of MAUI* #77 is a curated stop for developers tracking .NET MAUI Update, Welcome to .NET MAUI, Upcoming Media Element, Fresh Telerik UI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET MAUI Update** — .NET MAUI developers need to be nimble-footed to stay on the bleeding edge. .NET Release Candidate (RC) 2 . 4 Preview 4 is now out for both Windows and MacOS. .NET 7 RC1, but the big update in this latest release is support for latest in Apple ecosystem—AKA XCode 14 and iOS 16.
- **Welcome to .NET MAUI** — .NET MAUI has been moving fast—first to reach GA and to keep adding platform features to inspire developer confidence. .NET development for mobile/desktop apps. .NET MAUI provides developers with choices as to how the visual layer is built—pure XAML, pure C#, XAML with C#, with/without MVVM design and with preferred tooling on Windows/MacOS.
- **Upcoming Media Element** — .NET MAUI app? .NET MAUI Community Toolkit. .NET MAUI Community Toolkit —folks have been hard at work to get the first preview out soon. .NET MAUI Community Toolkit? In short, everything—everything one expects from a full-featured media player component.
- **Fresh Telerik UI** — .NET cross-platform app development platform for mobile and desktop apps. While the framework provides the fundamentals, serious developers need some UI ammunition to light up app UX and ship apps faster. .NET MAUI can help—the most comprehensive UI component suite for cross-platform mobile/desktop apps.
- **History & Future of Web Technologies** — .NET MAUI aim to blend development stacks—code for web and native apps can coexist side by side. As developers, it helps to know where others stand and how technology stacks evolve over time—better understanding leads to empathy and knowledgeable decisions.
