Sam Basu's *Sands of MAUI* #67 is a curated stop for developers tracking .NET Conf Focus on MAUI, .NET Community Toolkit, Logging in .NET MAUI, DataBinding in .NET MAUI. It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **.NET Conf Focus on MAUI** — .NET releases. .NET technology stacks each time. .NET developers to look forward to. .NET MAUI. .NET MAUI development stack—from getting started, C# 11, Design, DevOps, Blazor integration, code reuse and a lot more.
- **.NET Community Toolkit** — .NET developers and are agnostic of any specific UI platform. .NET developer. 0—there is some history that makes this the first major release of the Toolkit. .NET Community Toolkit were originally part of the Windows Community Toolkit—a collection of helpers, extensions and custom controls for Windows development.
- **Logging in .NET MAUI** — .NET MAUI apps are shipped, developers should not be in the dark as to how users are using the UI or if how the app is behaving—logging details can help. Logging is the age old way of explicitly writing out events, either within app lifecycle or triggered by user actions, that app developers can later dig through for context.
- **DataBinding in .NET MAUI** — .NET cross-platform story going forward and it may be enticing new developers to take the plunge. If building apps with C#/XAML, a key concept for developers to understand is Data Binding—the magic glue that holds the connection between the UI and data objects in code.
- **.NET MAUI with Firebase** — .NET MAUI app is half the battle—the rest is testing and shipping the app, which is particularly tricky for cross-platform apps. Some apps are destined for the Store, but they should ideally be tested beforehand by real users—and some enterprise apps are meant to be used directly by end users.
