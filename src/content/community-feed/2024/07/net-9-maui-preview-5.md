.NET 9 Preview 5 adds a shared Blazor Hybrid/Web template and Android platform updates for MAUI. Edin Kapić walks through the template model, performance work, and API 35 bindings.

## What you'll learn

- **Blazor Hybrid and Web App template** — one Razor Class Library feeding both MAUI Hybrid and a Blazor Web App
- **Android startup** — roughly 15% faster cold starts via LLVM marshalling (disabled for Blazor MAUI projects while a hang is investigated)
- **Android 15 Beta 2** — bindings for the advancing platform beta
- **Release trimming** — size reductions in Release mode you can toggle in the project file
