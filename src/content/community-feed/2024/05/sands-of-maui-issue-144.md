It brings together timely resources from the .NET MAUI ecosystem, with enough context to help you decide which original posts, videos, and announcements to open next.

## In this issue

- **Xamarin Gave Me** — .NET development to reach mobile platforms of iOS, Android and more. .NET for Mac. .NET MAUI. Forms—the official GitHub repositories were archived. .NET development. Forms developer community took the opportunity to look back at the journey with \#XamarinGaveMe .
- **.NET MAUI Community Standup** — .NET development stack reaching mobile/desktop from a shared codebase. .NET MAUI and provide updates—a wonderful way to bring the developer community together. .NET MAUI Community Standup was all about looking ahead at the future, while fondly remembering the past.

Keyboard accessibility can often be tricky—app navigation and functionality needs to be completely useable with only the keyboard.
- **Desktop UX with .NET MAUI** — .NET MAUI designed for building modern, multi-platform, natively compiled iOS, Android, macOS and Windows apps, using C# and XAML in a single codebase. Forms with a very mobile-first mindset. While the shared codebase is nice, desktop apps often have to support heavy usage and demand very different user experiences.
